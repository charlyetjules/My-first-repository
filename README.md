# Aether Visual Client (Fabric, Minecraft 1.21.1)
Build: `./gradlew build` (needs JDK 21 + internet; add the Gradle wrapper with `gradle wrapper` if missing).
Jar output: `build/libs/aether-client-2.4.1.jar` -> drop into `.minecraft/mods` with Fabric Loader + Fabric API.
In-game: press Right Shift. Module toggles are visual only.
